Link26 Android

버전 1.0.0+20 · 배포: link26-frontend.vercel.app

APK 다운로드

설치

  1. Android 설정에서 출처를 알 수 없는 앱 설치 허용(브라우저 또는 파일 앱).
  2. APK 설치 후 실행.
  3. 복약·간편인증은 서버 BFF가 필요합니다. 같은 웹 서버의 link26-bff.json 에 HTTPS BFF 주소가 있어야 합니다.

서버에 함께 올릴 파일

  • index.html (이 페이지)
  • Link26-*.apk (dist/ 에서 복사)
  • link26-bff.json — 예: tool/web_download/link26-bff.manifest.example.json 참고

디버그 APK·개발용 dotenv(집 IP, API 키)는 공개 업로드하지 마세요.
